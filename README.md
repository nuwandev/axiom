# Axiom

Authenticated server-side automation agent for Linux servers. Lets trusted
CI/CD systems (Jenkins) trigger predefined, server-local actions over
HTTPS+mTLS without SSH access.

Full specification: [docs/SPEC.md](docs/SPEC.md)

Status: pre-implementation. See [CLAUDE.md](CLAUDE.md) for project rules and
[docs/decisions/](docs/decisions/) for any deviations from the spec.
